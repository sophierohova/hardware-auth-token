# Разработка Электронного Ключа на базе Arduino Uno
Проект представляет собой программно-аппаратный комплекс двухфакторной аутентификации. Доступ к персональным данным (визитке) открывается только после успешной проверки физического токена.
Проект выполнили: Ерохова Софи и Салаватова Самира**

### 1. Алгоритм Challenge-Response

1. Программа на ПК генерирует случайное число от 0 до 255 (`Challenge`) и отправляет его через COM-порт.
2. Плата Arduino считывает байт, выполняет побитовое отрицание (`NOT`) и возвращает результат.
3. ПК складывает исходный байт и ответ. По законам булевой алгебры сумма всегда равна `0xFF`. Если это так — личность подтверждена и выводится визитка.

### 2. Реализованные меры безопасности

* **Защита от повтора:** Вместо фиксированного пароля каждый раз отправляется случайный байт (`rand() + time`). Перехват старой сессии ничего не даст взломщику.
* **Защита от зависания софта:** Настроена структура `COMMTIMEOUTS`. Если выдернуть плату из USB во время проверки, программа не зависнет намертво, а закроется по таймауту (50 мс).
* **Блокировка порта:** Порт открывается функцией `CreateFileA` в монопольном режиме (`dwShareMode = 0`). Другие программы в ОС не смогут внедриться в канал связи.

### 3. Дальнейшее развитие
* **Защита от клонирования:** Выставление битов защиты памяти (**Lock Bits**) микроконтроллера ATmega328P для запрета считывания прошивки злоумышленником через программатор.
* **Усиление криптографии:** Замена побитовой инверсии на алгоритм SHA-256.
